Homie

A sidebar browser for the Mac.

Download

  • Homie for Apple siliconmacOS 12 or later
  • Homie for IntelmacOS 12 or later

Unzip, move Homie to Applications, open it. All versions are on the releases page.

What it is

Pinned sites live in one bookmarks.yml you can keep in git and share between your Macs. Everything else goes in a Today list that clears itself. Built on Chromium, so sign-ins, passwords and notifications work as they do in Chrome.

What it does

  • Pinned sites in folders: drag to reorder, rename, give a folder an emoji
  • Split view, up to four panes side by side
  • A Today list for the tabs you do not want to keep
  • Chrome extensions from the Web Store
  • One bookmarks file for all your Macs
